# FanchmWrt 25.12.5 升级设计

## 目标

将 FanchmWrt 从 OpenWrt `v25.12.4` 升级到 `v25.12.5`，保留自有软件包、设备支持、feed overlay 和中文文档。升级只写入用户 fork，不创建 Pull Request，也不改变 OpenWrt 上游。

## 基线与边界

- 旧基线：`ba915c2ee711d047d5be8575c1e98699119429ab`（`v25.12.4`）。
- 新基线：`f0a60eee2fe051741c643ea6118718aae1ef17fb`（`v25.12.5`）。
- `fanchmwrt-25.12.4` 保持不变，作为源码和固件回退点。
- 所有 Git 与 feed 网络访问均使用直连，不使用代理。

## 集成方式

新分支从 `v25.12.5` 建立，按层恢复 FanchmWrt 定制，不在旧分支上直接合并上游。共享文件先接受上游的 25.12.5 发布状态，再只恢复 FanchmWrt 语义；禁止用 `ours` 或 `theirs` 覆盖冲突。

必须保留的结果：

- 上游 `include/version.mk` 的 25.12.5 发行元数据。
- `package/base-files/image-config.in` 中的默认发行名 `FanchmWrt`，以及 `releases/25.12.5` 发布地址。
- v25.12.5 的五个官方 feed 固定版本；FanchmWrt feed 暂时保持 `fdfa9a6f8e02ab9ad10e2961271ba9a4fa872458`。
- H3C Magic NX30 Pro Stock 和 JCG Q30 Pro Stock 的 DTS、网络、无线 MAC 与镜像定义。
- FanchmWrt 的 `fwx`、`fwxd`、LuCI 主题和 overlay 机制。

## 风险与验收

内核从 6.12.87 升至 6.12.94，`950-fwx-nf-conn-struct-user-hook.patch` 和 `fwx` 是最高风险边界。Mediatek Filogic 的共享文件需同时保留 FanchmWrt 条目与上游新增设备。最终验收在 Ubuntu 22.04 或兼容 Linux 运行 feeds、定制包、完整镜像和备用设备运行时测试；原生 Windows 仅用于静态检查。
