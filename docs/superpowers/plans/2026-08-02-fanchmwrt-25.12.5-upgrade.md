# FanchmWrt 25.12.5 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebase the FanchmWrt customization layer on official OpenWrt v25.12.5 while preserving FanchmWrt packages, stock-layout devices, build overlays, and release identity.

**Architecture:** Start with the immutable v25.12.5 tag and restore only the FanchmWrt layer in reviewed groups. For shared files, retain upstream release fixes and add the custom behavior back explicitly; validate release metadata before compiling custom kernel-dependent packages.

**Tech Stack:** OpenWrt 25.12, GNU Make, POSIX shell, Git, UCI/ubus, Linux 6.12, FanchmWrt fwx/fwxd.

## Global Constraints

- Base commit: `f0a60eee2fe051741c643ea6118718aae1ef17fb` (OpenWrt `v25.12.5`).
- Preserve branch `fanchmwrt-25.12.4`; never force-push or modify it.
- Direct network only: Git operations use `-c http.proxy= -c https.proxy=`.
- No Pull Request and no OpenWrt upstream writes; publish only `fanchmwrt-25.12.5` to the user's `origin` fork.
- Keep `FanchmWrt` as default distribution name.
- Use v25.12.5 official feed pins and retain custom feed pin `fdfa9a6f8e02ab9ad10e2961271ba9a4fa872458`.
- Full firmware acceptance runs on Ubuntu 22.04 or compatible Linux, never native Windows Make.
