# 下载与刷写

刷写是与具体硬件强绑定的操作。本文不提供“适用于所有设备”的命令；只有在镜像、设备和当前分区布局完全匹配时，才应继续。

## 获取镜像前

1. 从可核实的项目发布记录或自行构建结果取得镜像，并保留版本与提交信息。
2. 对照镜像文件名、构建配置和目标 Profile，确认它对应你的设备。
3. 核验校验和或签名（若发布记录提供），并确认镜像没有被二次修改。

## 刷写前

- 确认设备的分区布局与升级路径；不同容量或扩容布局不能默认兼容。
- 明确所需镜像类型，以及当前系统、引导加载器或厂商恢复工具的要求。
- 导出可恢复的配置，并准备断电、失败或无法启动时的救援方法。

## 不确定时停止

缺少设备 Profile、分区表或升级说明时，不要猜测命令，也不要使用强制选项。请先阅读[支持边界](supported-devices.md)，并按[支持说明](../../SUPPORT.md)整理设备、版本和日志信息。
