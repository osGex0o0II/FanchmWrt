# 支持边界与设备核验

本仓库不在文档中维护一份未经持续验证的“全设备支持列表”。设备能否使用某个镜像，应由构建目标、设备 Profile、分区布局和发布说明共同确认，而不是仅按设备名称判断。

## 刷写前核对清单

- 设备的 SoC、目标平台和板级标识与镜像的目标和 Profile 完全匹配。
- 当前设备的分区表、闪存容量和引导加载器要求与镜像升级路径兼容。
- 使用的镜像类型（例如 sysupgrade 或 factory）与当前系统及厂商刷写方式匹配。
- 升级前已备份可恢复的配置，并确认了可靠的救援或回退方法。

## 不在支持承诺中的情形

没有经过本仓库发布或构建记录验证的设备、特殊大分区布局、跨项目移植的内核模块，以及依赖闭源驱动的方案，都不能因名称相近而推定得到支持。需要新增设备时，请按[软件包和设备开发](../development/package-and-device-work.md)提供可复现的板级信息和构建证据。

## 遇到不确定性时

不要使用强制刷写命令来替代核验。请先查阅[下载与刷写](download-and-flash.md)和[获取支持](../../SUPPORT.md)中要求的信息，再决定后续操作。
