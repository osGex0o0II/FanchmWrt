# 软件包和设备开发

贡献应尽量聚焦于一个可验证的目的：新增或修复 FanchmWrt 自有软件包、增加经过验证的设备支持，或改善构建与文档流程。提交前请先阅读[贡献指南](../../CONTRIBUTING.md)。

## 软件包工作

- 将 FanchmWrt 自有软件包放在 `package/fanchmwrt/`，保持既有软件包名与依赖兼容。
- 为可执行脚本、覆盖层和关键构建逻辑提供可重复运行的检查。
- 更新外部 feed 固定版本时，记录直连解析到的提交，并审阅变化范围。

## 设备工作

- 明确目标平台、DTS 或板级改动、镜像 Profile 与测试硬件。
- 提供构建日志和非破坏性的验证证据；刷写测试必须说明分区布局和恢复方式。
- 不要以强制刷写或未经验证的闭源驱动作为默认兼容方案。

## 提交范围

不要把无关格式化、二进制资产或未验证的设备配置混入功能提交。与 OpenWrt 核心目录有关的改动应说明上游关系和兼容性影响。
