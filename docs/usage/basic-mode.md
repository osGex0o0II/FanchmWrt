# 基础模式使用说明

不同镜像是否包含 FanchmWrt 的自有组件，取决于构建配置。首次使用时，应先确认设备已按匹配的 Profile 刷写，再逐项核对已启用的网络、策略与 LuCI 功能。

## 建议的核对顺序

1. 确认设备网络连接、地址分配和基础访问正常。
2. 在 LuCI 中确认已安装的软件包和页面，不把未包含的页面当作故障。
3. 变更应用策略或网络规则前，先导出当前配置，并为管理访问保留恢复路径。
4. 修改后以可复现的客户端、域名或流量场景验证结果，并保存必要日志。

## 使用边界

本文不承诺某一特定设备、软件源或第三方服务一定可用。若问题与设备分区、镜像匹配或软件源格式有关，请先阅读[支持边界](../getting-started/supported-devices.md)和[故障排查](../build/troubleshooting.md)。
